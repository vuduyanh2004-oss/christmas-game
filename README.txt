CHRISTMAS QUESTS — MOBILE-READY PROTOTYPE

HOW TO PLAY ON YOUR PHONE
1. Extract this ZIP.
2. Upload the contents of the Christmas_Quests folder to a static web host (GitHub Pages, Netlify, etc.). Keep index.html and the assets folder together.
3. Open the published link in Safari or Chrome on your phone.
4. Turn your phone sideways (landscape). The game will use the available screen area.
5. On iPhone, you can use Share > Add to Home Screen for a more app-like launch.

DESKTOP
Open index.html in a modern browser. The prototype is designed around a 852 x 393 landscape scene and scales to fit the browser window.

NOTES
- Portrait mode displays a rotate-your-phone prompt because the supplied artwork and puzzle composition are landscape.
- This is a web game prototype; it does not yet include native app installation or offline caching.
